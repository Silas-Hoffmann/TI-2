# TI 2 - Trabalho Interdisciplinar 2

Este repositório contém as atividades e exercícios desenvolvidos durante a disciplina de Trabalho Interdisciplinar 2.

---

### 📋 Organização

Cada **branch** representa a solução de um exercício diferente. A estrutura permite manter as soluções isoladas e bem organizadas.

---

### 🚀 Como usar

1. **Visualizar os exercícios:**
   ```bash
   git branch -a
   ```

2. **Acessar um exercício específico:**
   ```bash
   git checkout <nome-do-branch>
   ```
